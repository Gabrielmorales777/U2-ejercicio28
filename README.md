# U2-ejercicio28
# Sistema de Autenticación de Usuarios

**Objetivo principal:** desarrollar un sistema modular de autenticación en Java utilizando interfaces y polimorfismo para validar identidades mediante diferentes mecanismos.

El ejercicio implementa la interfaz `MetodoAutenticacion` y tres clases concretas: `AuthPassword`, `AuthBiometrica` y `AuthTokenOAuth`. Además, incorpora un `ServicioLogin` que procesa los intentos de inicio de sesión sin depender de un mecanismo específico.

Se simulan autenticaciones exitosas y fallidas mediante los distintos métodos disponibles.

**Conceptos aplicados:** interfaces, implementación, polimorfismo, encapsulamiento, sobrescritura de métodos y desacoplamiento.
